# About the data

For this study, I've been collecting academic records from Notre Dame College's HSC 2026 batch. My working file contains 20 histories transcribed from supplied report cards and 11 more entered from handwritten notes. Some of the report cards are incomplete, and I still need to check the handwritten entries against their original sources. I also created four synthetic histories to test the software; those aren't student observations.

Each report card has more useful detail than its final average. The Term report shows three quiz marks and an exam mark for each subject. Sent Up I adds four quizzes and another exam, and Sent Up II includes five quiz columns and its exam. Not every subject has a mark in every quiz column, so a dash isn't automatically a zero. I've kept entries such as `Ex` and `Ab` as printed instead of treating them all the same.

The private working spreadsheet holds all three categories (35 entries in total), but each entry has a source label. That count is **not** the study's analyzed sample size. The 11 histories entered from offline notes still need to be checked against their source records, and the four generated examples are for software testing only. **The first public results use only the 20 histories transcribed from supplied report cards.** I haven't published the working spreadsheet as a dataset containing 35 genuine student records.

The actual analysis will use only marks that I can tie back to collected records. I also won't upload the report card images or individual level data here; they include personal academic information.

What I'm interested in is fairly simple to explain: if someone's mark drops from one quiz to another, did their standing among the *same participating students* drop too? For now, that question is more useful than a claim about which paper was harder or which measure is fairer.
