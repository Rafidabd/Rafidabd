# Hi, I'm Rafid 👋

I'm a student at Notre Dame College in Dhaka, Bangladesh. I started learning Python through small exercises, but eventually I wanted to build things I could keep improving instead of just writing a script and moving on.

A lot of what I build is connected to education. I've become interested in what student records can show beyond a single exam result, especially when you look at progress over time.

### What I'm working on

**[Bangladesh Academic Analytics System](https://github.com/Rafidabd/python-phase-1/tree/main/academics_analytics_system)** — *in development*

This is my biggest project so far. It began as a Python command-line program for working with student performance data, then grew into a Flask web application with dashboards and academic analysis.

Lately I've been adding an **Admission Prep** side to it: course and topic planning, study schedules, assessments, and ways to review study sessions. Building the web interface has pushed me to learn and use HTML, CSS, JavaScript, and Jinja templates. I've also worked on SVG and Canvas effects for some of the dashboard visuals.

**The code on GitHub is an older snapshot.** A lot of the Admission Prep work is still in my local development version, so I don't want the public repository to suggest those features have already been released.
