# Hi, I'm Rafid 👋

I'm a student at Notre Dame College in Dhaka, Bangladesh. A lot of my free time goes into Python projects. I started with small exercises, and over time I found myself wanting to build programs that someone could actually use.

I'm especially interested in what we can learn from academic data. A single exam result tells you something, but looking at results over time can tell a very different story. That's one of the ideas I'm exploring in my current project.

### What I'm working on

**[Bangladesh Academic Analytics System](https://github.com/Rafidabd/python-phase-1/tree/main/academics_analytics_system)** — *still in development*

My biggest project so far. I'm building it with Python and Flask to work with student records, performance trends, and different ways of understanding academic progress. The version on GitHub is an older development snapshot; I'm still working on the newer version locally.
