# Hi, I'm Rafid 👋

I'm a Class 12 student at Notre Dame College, Dhaka. I started learning Python by writing small programs, and eventually got interested in building something bigger than a single script.

Most of my work so far has been around student data and education.

### Research in progress

**[When 80 Doesn't Mean the Same](research/when-80/README.md)**

A result from my own mathematics quiz made me question how I'd been comparing marks across different exams. I'm now collecting historical results from NDC's HSC 2026 cohort to examine raw scores alongside students' relative standing in the same assessments.

The research page has the [short brief](research/when-80/BRIEF.md), [methods](research/when-80/METHODS.md) and [progress notes](research/when-80/PROGRESS.md). Data collection is still underway; I haven't reported findings yet.

### What I'm building

**[Bangladesh Academic Analytics System](projects/bangladesh-academic-analytics-system/README.md)** (in development)

This started as a Python CLI for storing and analyzing student results. I later moved it to Flask and began building a web interface around it. It handles academic histories, trends, risk flags, heuristic predictions and other analyses.

I'm also working on an Admission Prep section, with course topics, schedules, assessments and error tracking. I've used HTML, CSS, JavaScript and Jinja templates along the way.

A cleaned [code snapshot](projects/bangladesh-academic-analytics-system/README.md) is public now. It doesn't include every change from my local version.
